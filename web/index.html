About the solver

Lattice-Boltzmann (D3Q19) with a regularized collision and Smagorinsky large-eddy turbulence model, running on the server's NVIDIA GPU (CUDA via Warp) and streamed to this page. Inlet at free-stream speed, far-field side walls, zero-gradient outlet. Forces use momentum exchange; Cd and Cl use the frontal or planform area you choose. The grid is coarse, so expect qualitative flow structure and ballpark coefficients — not certified CFD.
